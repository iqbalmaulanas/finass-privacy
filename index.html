Kebijakan Privasi

Aplikasi: FinAss - Finansial Assistant (com.ims.finass)
Pengembang: IMS • Berlaku sejak: 10 November 2026

Kebijakan Privasi ini menjelaskan bagaimana aplikasi FinAss - Finansial Assistant ("Aplikasi") mengelola informasi saat Anda menggunakan aplikasi ini pada perangkat Android Anda. Dengan menggunakan Aplikasi, Anda menyetujui praktik pengelolaan data yang dijelaskan di bawah ini.

Ringkasan Utama: FinAss tidak memerlukan akun atau login cloud. Seluruh catatan keuangan Anda disimpan secara lokal di perangkat Anda sendiri dan tidak pernah diunggah ke server pengembang.

1. Data Keuangan yang Anda Catat (Penyimpanan Lokal)

Aplikasi menyimpan data yang Anda masukkan secara langsung, antara lain:

  • Profil lokal beserta preferensi target tabungan dan dana darurat.
  • Catatan transaksi pemasukan, pengeluaran, dan kategori kustom.
  • Batas anggaran bulanan per kategori.
  • Catatan hutang, piutang, jadwal jatuh tempo, dan riwayat cicilan/pembayaran.
  • Pengaturan jadwal pengingat harian dan peringatan lokal.

Semua data di atas disimpan 100% secara lokal di memori perangkat Anda. Pengembang tidak memiliki akses, tidak mengumpulkan, tidak menjual, dan tidak mengirimkan catatan keuangan Anda ke server mana pun.

2. Iklan Pihak Ketiga (Google AdMob)

Untuk mendukung layanan aplikasi secara gratis, Aplikasi menampilkan iklan melalui layanan pihak ketiga Google AdMob (Google LLC), termasuk format Banner, Native, dan Interstitial.

Saat memuat dan menayangkan iklan, SDK Google Mobile Ads dapat mengumpulkan dan memproses data teknis secara otomatis sesuai kebijakan Google, meliputi:

  • ID Iklan Android (Advertising ID) untuk penayangan dan pembatasan frekuensi iklan.
  • Alamat IP (dapat digunakan untuk memperkirakan lokasi umum seperti negara/kota).
  • Informasi perangkat dan sistem operasi (model perangkat, versi Android, bahasa, pengenal perangkat SDK).
  • Data interaksi dengan iklan (penayangan, klik iklan) dan diagnostik performa SDK.

Pelajari selengkapnya mengenai pengelolaan data oleh Google melalui tautan resmi berikut:

  • Kebijakan Privasi Google
  • Cara Google Menggunakan Informasi dari Aplikasi Mitra
  • Kebijakan & Privasi Google AdMob

Anda dapat mengatur ulang atau menonaktifkan personalisasi iklan kapan saja melalui setelan perangkat Android Anda (Setelan > Google > Iklan atau Setelan > Privasi > Iklan) serta melalui Setelan Iklan Google.

3. Izin Aplikasi & Fitur Ekspor

  • Internet & Status Jaringan (INTERNET, ACCESS_NETWORK_STATE): digunakan oleh SDK Google AdMob untuk memuat iklan serta membuka tautan mitra iklan saat Anda mengetuk iklan.
  • Notifikasi & Mulai Ulang Perangkat (POST_NOTIFICATIONS, RECEIVE_BOOT_COMPLETED): digunakan untuk menampilkan pengingat lokal di perangkat Anda (seperti pengingat catat transaksi harian, jatuh tempo hutang/piutang, dan batas anggaran). Seluruh penjadwalan berjalan lokal di perangkat tanpa server push eksternal.
  • Ekspor Laporan CSV & Berbagi: saat Anda menekan tombol konfirmasi ekspor CSV, file laporan dibuat secara lokal di direktori penyimpanan aplikasi dan disalin ke clipboard atau dibagikan hanya apabila Anda memilih untuk membagikannya melalui menu Share Android.

4. Keamanan & Penghapusan Data Anda

Karena seluruh data keuangan tersimpan langsung di perangkat Anda, Anda memegang kendali penuh untuk menghapusnya kapan saja melalui:

  • Menu Setelan > Hapus Data Profil Ini di dalam aplikasi, atau
  • Setelan Android > Aplikasi > FinAss > Penyimpanan > Hapus Data, atau mencopot pemasangan (uninstall) aplikasi.

5. Privasi Anak

Aplikasi ini ditujukan untuk pengguna umum dan tidak dirancang khusus untuk anak-anak di bawah usia 13 tahun. Pengembang tidak secara sengaja mengumpulkan informasi pribadi dari anak-anak.

6. Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui sewaktu-waktu apabila ada perubahan fitur atau ketentuan hukum/platform. Perubahan terbaru akan ditampilkan pada halaman ini beserta tanggal berlaku yang diperbarui.
